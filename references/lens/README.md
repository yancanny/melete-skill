# 照见图谱（Melete Lens）

> 状态：草案，待发起人审阅。版本见 `CHANGELOG.md`。许可：CC BY 4.0。
> 名称"照见图谱"是工作名。

照见图谱是 Melete 的内核：一张"怎么看"的网，不是一张"怎么评"的表。它告诉做回顾的 AI 从哪些方向看、每个方向沿哪些维度看、在记录里看哪里、看到之后有哪些可能的读法、什么不能推断。好坏由用户自己定义。

## 怎么用

**在能读文件的 Agent 里**（DSH、Claude Code、Codex 等）：

> 读 `melete/references/lens/` 下的 values、network、procedure，按"回顾的做法"回顾我最近两周的对话，生成我的 Melete。

**在网页对话里**（ChatGPT、DeepSeek 等）：上传或粘贴 `export/lens-for-chat.md`，再说：

> 按这份图谱的"回顾的做法"，回顾我们之前的对话（或我上传的导出文件），生成我的 Melete。

**只看某一面**：

> 用照见图谱，只看我最近的 H2 求证，和 AI 那一侧的 A2 诚实。

**将来**：图谱会允许别人写、允许你自己定义；每份图谱有自己的名字，回顾会记明用的是哪一份，旧回顾始终能读。

**将来的插件**：读 `export/lens.json`，或直接读这些 Markdown。

## 维护

一个维度的写法：

```markdown
### H1.1 起意 · 方向从哪里来

- 形状：两端
- 两端：你带着方向来 ⟷ 请 AI 先给方向
- 看哪里：……
- 多种可能：
  - ……
  - ……
- 不推断：……
- 需要：正文
- 相连：H4.1、A3.3
```

- **字段**：形状（两端、分布、出现）；两端（形状为两端时，用 ⟷ 隔开两头）；种类（形状为分布或出现时，用顿号隔开）；看哪里；多种可能（至少两条）；不推断；需要（正文、动作、时间、跨会话、自述、上次回顾）；相连（可选）；说明、依据（可选）。
- **方向的字段**：问、在乎（指向 `values.md` 里的价值名）、未来（十年尺度上这个方向会变成什么样），说明、依据（可选）。
- **面向未来**：方向和维度用关系来写，不绑定界面；"看哪里"会随时代换，换线索不换问题（见 `network.md`）。
- **编号**：一经发布永不改、永不复用。新维度取该方向的下一个编号；停用的在 `CHANGELOG.md` 里注明。
- **版本号**：删除维度或改变含义 → x 加一；新增维度或方向 → y 加一；只改措辞 → z 加一。回顾报告记下所用版本，下次对照前先看版本变了没有。
- **写作约束**：域文件里不出现"依赖、过度、不足、缺乏、应该"（工具会检查）；"两端"的两头都要写得合理；"出现"形状的维度只列出现的。
- **检查与生成**（维护者工具，不随 Skill 发布；需要 Node 22.18 或更新版本）：
  - `node tools/lens.ts check`：只检查，不改文件。
  - `node tools/lens.ts build`：检查，刷新 `network.md` 里的索引，重新生成 `export/`。
- **方法卡**（将来的建议库）指向维度，而不是维度指向方法卡：图谱保持稳定，方法可以长得快。
