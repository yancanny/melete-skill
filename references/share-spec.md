# 分享：放什么、不放什么

> 版式只用 `assets/share.html`，不要从零手写。你可以在模板允许的范围内调颜色和措辞，但不要加新版块。

## 什么时候做

- 只在用户要的时候做（"做成长图""分享版""发朋友圈用"）。
- 先出**长图**；交付后问一次"要不要再给你一份 HTML？"

## share.json

```json
{
  "lang": "zh",
  "kind": "year",
  "title": "我的 2026 · 和 AI 一起的一年",
  "range": "2026.01.01 – 2026.11.08 · 截至今天",
  "by": "由 Claude 回看",
  "numbers": [
    { "value": "312", "label": "段对话" },
    { "value": "写作", "label": "我最常和 AI 一起做的事" },
    { "value": "深夜", "label": "我最常找 AI 的时候" }
  ],
  "mirrors": [
    { "title": "写作时，我常常直接用初稿", "line": "也许是周报本来就不值得多花时间；也许有几次，我其实想留下自己的说法。" }
  ],
  "ai": "AI 有几次在没有依据时答得很笃定。",
  "question": "十年后，我希望哪些事仍然由自己亲手做？",
  "experiment": "",
  "name": "",
  "signature": true
}
```

| 字段 | 说明 | 上限 |
|---|---|---|
| `lang` | 页面语言（`zh`、`en` 等），影响版块标题 | — |
| `kind` | `year`（年度、近 1 年、全部）或 `short`（7–90 天、短的自定义时间段） | — |
| `title` | 标题，用第一人称 | 24 字 |
| `range` | 起止日期；当年未完时写"截至今天" | — |
| `by` | 谁在看，例如"由 Claude 回看" | — |
| `numbers` | 大数字，可省略 | `year` 最多 3 个，`short` 最多 2 个 |
| `mirrors` | 几面镜子：一句观察 + 一句读法 | `year` 最多 3 面，`short` 最多 2 面 |
| `ai` | AI 这一侧，一句 | 60 字 |
| `question` | 一个开放的问题 | 40 字 |
| `experiment` | 小实验，没有就留空（只在用户有意图时才有） | 60 字 |
| `name` | 用户的署名，默认留空；用户给了才填，**不要从记忆里自动带上** | — |
| `signature` | 底部"Melete · 我的 AI 复盘"签名条，用户可以关 | — |
| `labels` | 可选：覆盖版块标题，用于其他语言 | — |

## 配方

- **年度**：大数字（最多 3 个）→ 三面镜子 → AI 这一侧 → 一个问题 → 小实验（有才放）。
- **短期**：最多 2 个数字 → 两面镜子 → AI 这一侧 → 一个问题。

## 写法

- 用第一人称（"我"），因为这是用户发出去的东西。
- 一句观察 + 一句读法；读法至少一种说明它完全合理的时候。
- 数字只来自本机统计，只说用户自己；**缺数据就不放，不编**。"我最常……"可以用文字代替数字。
- **默认不放原话**：用户的原话可能涉及别人或工作内容。

## 永远不放

- 写给你自己的信（域四"自己"）的任何内容，包括信封；情绪与健康的猜测、病名、诊断。
- 邮箱、电话、密钥、令牌、文件路径、会话编号、项目名、他人姓名。
- 分数、百分比、百分位、排名、等级、人格类型、和他人的比较。
- 外部资源：字体、图片、脚本、统计代码。分享出去的文件里不含任何脚本。

## 交付前检查（不能运行脚本时，逐条手工核对）

- [ ] 数字和镜子没有超过上限？
- [ ] 没有禁用词（`report-template.md`）？
- [ ] 没有写给你自己的信的内容、没有健康猜测、没有原话、没有隐私信息？
- [ ] 没有分数、百分比、排名、人格类型？
- [ ] 文件里没有 `<script>`、没有 `http://` 或 `https://` 的外部资源？
- [ ] 署名是空的，或者是用户这次亲口给的？
